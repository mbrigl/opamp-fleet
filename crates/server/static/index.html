a file or source url named <name>_<version>_<os>_<arch>.7z fills the platform — and, while creating, whatever of the name, agent type, and version is still empty (- or _)
A deployment is a name, the channel it aims at, one package per agent type, and the signature of each artifact. An agent belongs to at most one: two matching the same agent is a conflict, and that agent is offered nothing new until a selector is narrowed. There is no fleet-wide default — a selector is equality and cannot say "not", so channels are a partition over an attribute every agent carries (channel = stable), set at provisioning or as a label on the Agents tab.
