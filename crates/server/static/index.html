Configurations — each targets the Agents its Selector matches; an empty Selector targets every Agent

Packages — a software artifact offered to the Agents its Selector matches; verified (content hash, and signature when a key is configured), then swapped and health-gated. One name carries one artifact per platform, and an Agent is only ever offered the one built for the machine it reported. A package also states the agent type it is built for, matched against the agent's service.name: without one it reaches nobody, and it never reaches an agent of another type whatever its Selector says. An empty Selector then targets every agent of that type; a narrower one overrides it for the agents it names — which is how a rollout starts on part of the fleet.
